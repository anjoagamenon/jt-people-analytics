Fotos da operação

No celular, “Tirar foto” abre a câmera; “Enviar arquivo” abre a galeria/arquivos. O carimbo é no estilo Timemark: selo com logo + hora, data, endereço, mini-mapa, código de verificação e marca d’água.

♿ Libras e áudio relatório acessível e compartilhável

Pronto. O vídeo usa o fluxo oficial do VLibras: texto → glosa → vídeo.
⚙ Configuração da API de vídeo (avançado)

O endpoint público traduz texto → glosa, mas a geração de vídeo hoje exige uma API própria/token. Com um self-host do VLibras ou um token válido, o botão gera o vídeo e permite compartilhar. Sem vídeo, “Compartilhar” envia o resumo e o PNG.

🗂️ Histórico salve, revise e reenvie versões depois

Cada versão guarda o relatório completo (dados e fotos) no aparelho. “Abrir” carrega a versão para edição; “PNG” reexporta na hora; “Excluir” apaga.
